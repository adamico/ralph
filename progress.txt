13	issue-13-session-marker: Added .ralph-logs/<scope>/running session marker file creation and cleanup in non-interactive iterate_once(). When a session starts, a file containing the current shell PID ($$) is written to .ralph-logs/<scope>/running; a trap EXIT is set to remove the file on exit (COMPLETE, BLOCKED, error, or normal end). This allows `ralph inspect` to detect live sessions. Trap ensures cleanup happens even on interrupt (Ctrl+C). Added tests to pick_next_issue_spec.sh to verify file creation and cleanup. All tests pass (16/16 assertions). Bash syntax verified. Ready for `ralph inspect` to use this marker.
